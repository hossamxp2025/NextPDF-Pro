NextPDF Pro 1.1.0 - دليل الاستخدام
===================================

مرحبًا بك في NextPDF Pro، محرر PDF لسطح مكتب Windows بواجهة عربية وإنجليزية.

محتويات الحزمة
--------------
- NextPDF-Pro.exe: التطبيق المستقل (لا يحتاج Python)
- README.txt: هذا الملف
- VERSION.txt: الإصدار ومعرّف البناء
- LICENSE.txt: ترخيص التطبيق
- LICENSES.txt: تراخيص المكتبات الخارجية
- SHA256SUMS.txt: بصمات SHA-256 للتحقق من سلامة الملفات
- TEST_REPORT.txt: ملخص نتائج الاختبارات المنفذة

متطلبات التشغيل
---------------
- Windows 10 (64-bit) أو Windows 11 (64-bit)
- لا يحتاج Python ولا اتصالًا بالإنترنت
- لا يحتاج تسجيل دخول أو خدمة سحابية

الاستخدام
---------
1. شغّل NextPDF-Pro.exe.
2. اضغط "فتح" واختر ملف PDF.
3. لإضافة نص: اضغط "إضافة نص" ثم انقر على الصفحة، اكتب النص واختر
   الخط والحجم والاتجاه، ثم اضغط "تطبيق".
4. لتحرير نص موجود: اضغط "تحرير النص" ثم انقر على السطر. يُزال النص القديم
   من الصفحة ويُكتب النص الجديد في نفس الموضع.
5. "تراجع" و"إعادة" يعيدان محتوى PDF الحقيقي، وليس واجهة العرض فقط.
6. "حفظ" أو "حفظ باسم" يكتب ملفًا جديدًا. احتفظ بالنسخة الأصلية دائمًا.

الدعم الحالي
------------
- إضافة وتحرير وحذف النص العربي والإنجليزي مع تشكيل عربي صحيح
- إدراج الصور، وإدراج/حذف/تدوير/ترتيب الصفحات، واستخراج الصفحات ودمج الملفات
- البحث، الخصائص، الطباعة، التكبير/التصغير وملاءمة الصفحة
- تبديل الواجهة بين العربية (RTL) والإنجليزية (LTR) مع حفظ الاختيار

حدود معروفة (بدون ادعاءات مبالغ فيها)
-------------------------------------
- تحرير النص المدعوم للسطور الأفقية فقط. السطور المائلة أو الدوارة تُرفض
  برسالة واضحة بدل إنتاج نتيجة مشوّهة.
- النص العربي الذي يضيفه أو يعدّله البرنامج يُخزَّن كـ Unicode منطقي قابل
  للبحث والاستخراج (منذ 1.3.0). ملفات من برامج أخرى قد تظل بأشكال العرض.
- OCR مضمَّن ويعمل بلا تثبيت: المحرك داخل MuPDF والبيانات المشحونة هي
  العربية والإنجليزية فقط.
- التوقيعات الرقمية والتشفير والتحرير الآمن (redaction) ليست ضمن هذا الإصدار.
- لا يُدّعى التوافق الكامل مع Adobe Acrobat أو JOPDF.

الخصوصية
--------
يعمل التطبيق محليًا فقط. لا يرسل الملفات أو النصوص إلى أي خدمة خارجية.
تُحفظ الإعدادات والسجلات في:
%LOCALAPPDATA%\NextPDF-Pro

------------

LICENSES.txt قبل أي إعادة توزيع.
